# Aviso

Esta pasta é o pacote do curso de estilos: receitas, motores, prévias e o plugin `curso-estilos`.

Ela não entra na licença MIT da raiz deste repositório. Arquivos de terceiros continuam com a licença que já vem escrita ao lado deles.

Os estilos `#101`–`#199` entram pela skill `99-estilos` (catálogo, notas, prévias e kit do curso). A biblioteca [Lemo-Opuscar](https://github.com/lemomo-ai/lemo-opuscar) não está copiada aqui: o código é MIT, mas os textos de estilo são CC BY-NC 4.0 e não podem ser redistribuídos. Instale à parte com `claude plugin marketplace add lemomo-ai/lemo-opuscar` e `claude plugin install lemo-opuscar@lemolab`.
